# Portfolio Website – Dominik Waldburger

Dies ist die persönliche Portfolio-Website von Dominik Waldburger.  
Die Website dient dazu, ausgewählte Projekte, technische Interessen und berufliche Informationen übersichtlich darzustellen.

Sie richtet sich vor allem an Personen, die sich einen schnellen Eindruck von meinem technischen Profil, meiner Arbeitsweise und meinen bisherigen Projekten machen möchten.
